## 🇵🇹 Saying Where You're From

### Asking

| Portuguese | English | Register |
|---|---|---|
| **De onde és?** | Where are you from? | Friendly |
| **De onde é?** | Where are you from? | Formal |

### Answering

The basic pattern is:

**Sou + de/do/da/dos/das + country**

| Country | “I’m from…” |
|---|---|
| Portugal | **Sou de Portugal.** |
| Espanha | **Sou de Espanha.** |
| França | **Sou de França.** |
| Alemanha | **Sou da Alemanha.** |
| Itália | **Sou de Itália.** |
| Reino Unido | **Sou do Reino Unido.** |
| Estados Unidos | **Sou dos Estados Unidos.** |
| Paquistão | **Sou do Paquistão.** |
| Índia | **Sou da Índia.** |
| China | **Sou da China.** |
| Japão | **Sou do Japão.** |
| Brasil | **Sou do Brasil.** |
| Canadá | **Sou do Canadá.** |
| Austrália | **Sou da Austrália.** |
| Marrocos | **Sou de Marrocos.** |

### 🇵🇹 The important contractions

You don't simply say **de + country** every time.

- **de + o → do** → Sou **do** Paquistão.
- **de + a → da** → Sou **da** Índia.
- **de + os → dos** → Sou **dos** Estados Unidos.
- **de + as → das**

But some country names take just **de**:

- **de Portugal**
- **de Espanha**
- **de França**
- **de Itália**
- **de Marrocos**

### Country vs nationality

You can answer the question in two ways:

**De onde és?**
→ **Sou do Paquistão.** 🇵🇰
→ I'm from Pakistan.

Or:

**De onde és?**
→ **Sou paquistanês.**
→ I'm Pakistani.

You can combine them:

> **Sou do Paquistão. Sou paquistanês.**

### ⭐ A1 conversation

> **— De onde és?**
> — Sou do Paquistão.
> **— És paquistanês?**
> — Sim, sou.

For a woman:

> **— De onde és?**
> — Sou do Paquistão.
> **— És paquistanesa?**
> — Sim, sou.

**Key A1 pattern to memorize:**

> **De onde és? → Sou de/do/da + país.**
> **És + nationality? → Sim, sou + nationality.**

### 🇵🇹 One grammar point worth remembering

With cities, you will often use **em**:

- **em Lisboa**
- **em Coimbra**
- **em Paris**
- **em Londres**

But some cities commonly take an article:

- **no Porto** = em + o Porto
- **na Guarda** = em + a Guarda

So:

> **Vivo em Lisboa, mas nasci no Paquistão.** ❌

Better:

> **Vivo em Lisboa, mas nasci no Paquistão.** — actually **no Paquistão** is correct because *Paquistão* takes **o**.

The pattern is **em + article → no/na/nos/nas**.

**A:** Que línguas fala?
**B:** Falo inglês e urdu. Falo um pouco de português.

**A:** Está a aprender português?
**B:** Sim, estou a aprender português.

**A:** Até logo.
**B:** Até logo.

### ⭐ Your A1 conversation framework

You can think of the conversation as **8 steps**:

1. **Olá! / Bom dia!** → Greeting
2. **Como estás?** → How are you?
3. **Como te chamas?** → Name
4. **De onde és?** → Country/origin
5. **Qual é a tua nacionalidade?** → Nationality
6. **Onde vives?** → City/living
7. **Que línguas falas?** → Languages
8. **Até logo!** → Goodbye

If you can comfortably have this conversation **without translating in your head**, you've got a very solid foundation for the **A1 “personal information” section**.

## 🇵🇹 A1 Portuguese: Ages

The key thing to learn is that Portuguese uses **ter (to have)** for age, not **ser (to be)**.

### 1. Asking someone's age

| Portuguese | English |
|---|---|
| **Quantos anos tens?** | How old are you? — informal |
| **Quantos anos tem?** | How old are you? — formal |
| **Quantos anos ele tem?** | How old is he? |
| **Quantos anos ela tem?** | How old is she? |
| **Que idade tens?** | How old are you? |
| **Que idade tem?** | How old are you? — formal |

For A1, prioritize:

> **Quantos anos tens?**
> **Tenho 25 anos.**

### 2. Saying your age

**ter + number + anos**

- Tenho **18 anos**. = I'm 18.
- Tenho **20 anos**. = I'm 20.
- Tenho **25 anos**. = I'm 25.
- Tenho **30 anos**. = I'm 30.
- Tenho **41 anos**. = I'm 41.

Notice:

❌ **Sou 25 anos.**
❌ **Estou 25 anos.**
✅ **Tenho 25 anos.**

Literally, **Tenho 25 anos** means "I have 25 years."

### 3. Asking about other people

- **Quantos anos tens?** → How old are you?
- **Quantos anos tem o João?** → How old is João?
- **Quantos anos tem a Maria?** → How old is Maria?
- **Ele tem 30 anos.** → He is 30.
- **Ela tem 28 anos.** → She is 28.

### 4. Useful age expressions

| Portuguese | English |
|---|---|
| **Tenho 25 anos.** | I'm 25. |
| **Tenho quase 25 anos.** | I'm almost 25. |
| **Tenho mais de 25 anos.** | I'm over 25. |
| **Tenho menos de 25 anos.** | I'm under 25. |
| **Tenho 25 anos e meio.** | I'm 25 and a half. |
| **Fiz 25 anos.** | I turned 25. |
| **Vou fazer 26 anos.** | I'm going to turn 26. |

### 5. The most important A1 pattern

Memorize this mini-conversation:

**A:** Quantos anos tens?
**B:** Tenho 25 anos. E tu?
**A:** Tenho 27 anos.

> **Quantos anos tens? → Tenho ___ anos.**

That's the essential A1 age pattern.

**custa + number + euros**

In everyday speech, you will often hear the decimal price said more simply:

> **€5,50 → cinco e cinquenta**

The currency symbol in Portugal is **€**, and Portuguese writing normally uses a **comma** for decimals: **5,50 €**.

## 🇵🇹 A1 Portuguese: Numbers — Time

For A1, you need to learn how to **ask the time, tell the time, and talk about schedules**.

### 1. Asking the time

| Portuguese | English |
|---|---|
| **Que horas são?** | What time is it? |
| **Tem horas?** | Do you have the time? |
| **Sabe que horas são?** | Do you know what time it is? |

The most important:

> **Que horas são?**

Notice **horas** is plural because you're asking "what hours are they?"

---

### 2. Full hours

The basic pattern is:

**É uma hora.** → It's one o'clock.
**São duas horas.** → It's two o'clock.

| Time | Portuguese |
|---:|---|
| 1:00 | **uma hora** |
| 2:00 | **duas horas** |
| 3:00 | **três horas** |
| 4:00 | **quatro horas** |
| 5:00 | **cinco horas** |
| 6:00 | **seis horas** |
| 7:00 | **sete horas** |
| 8:00 | **oito horas** |
| 9:00 | **nove horas** |
| 10:00 | **dez horas** |
| 11:00 | **onze horas** |
| 12:00 | **doze horas** |

Important:

> **É uma hora.**
> **São duas horas.**

---

### 3. Minutes after the hour

Use:

**hora + e + minutos**

- 2:05 → **duas e cinco**
- 2:10 → **duas e dez**
- 2:15 → **duas e quinze**
- 2:20 → **duas e vinte**
- 2:30 → **duas e meia**
- 2:45 → **duas e quarenta e cinco**

You don't normally need to repeat **horas** when telling the time conversationally.

> **Que horas são?**
> **São três e vinte.**
> → It's 3:20.

---

### 4. Half past

**meia** = half

So:

**3:30 → três e meia**

Not:

❌ três e meio
✅ **três e meia**

Because **hora** is feminine.

---

### 5. Quarter past / quarter to

**e um quarto** = quarter past

- 4:15 → **quatro e um quarto**

For quarter to:

**menos um quarto** = quarter to

- 4:45 → **cinco menos um quarto**

This is useful, but for early A1 you can simply say:

> **quatro e quarenta e cinco**

---

### 6. Minutes before the next hour

You can use **menos**:

- 2:50 → **três menos dez**
- 4:45 → **cinco menos um quarto**
- 7:55 → **oito menos cinco**

So:

> **São cinco menos dez.**
> = It's 4:50.

For A1, however, **quatro e cinquenta** is perfectly useful and easier.

---

### 7. 24-hour time

Portugal commonly uses the **24-hour clock**, especially for schedules, transport, appointments, and official contexts.

| Time | Portuguese |
|---:|---|
| 08:00 | oito horas |
| 09:30 | nove e meia |
| 12:00 | meio-dia |
| 13:00 | uma da tarde |
| 14:30 | duas e meia da tarde |
| 18:00 | seis da tarde |
| 20:00 | oito da noite |
| 00:00 | meia-noite |

Useful expressions:

- **de manhã** = in the morning
- **da tarde** = in the afternoon
- **da noite** = in the evening/night
- **meio-dia** = noon
- **meia-noite** = midnight

---

### 8. Asking about schedules

This is where numbers + time become really useful:

**A que horas...?**
→ At what time...?

- **A que horas começa?** → What time does it start?
- **A que horas termina?** → What time does it finish?
- **A que horas abre?** → What time does it open?
- **A que horas fecha?** → What time does it close?
- **A que horas é o comboio?** → What time is the train?
- **A que horas é a aula?** → What time is the class?

Answer:

> **Começa às nove.**
> → It starts at nine.

> **A aula é às dez e meia.**
> → The class is at 10:30.

### 9. Important: **às**

**a + as = às**

So:

> **A que horas?** → At what time?
> **Às três.** → At three.
> **Às oito e meia.** → At 8:30.

But with one o'clock:

> **À uma.** → At one.

### 🎯 A1 priority

Memorize these first:

> **Que horas são?** = What time is it?
> **São três horas.** = It's 3:00.
> **São três e quinze.** = It's 3:15.
> **São três e meia.** = It's 3:30.
> **São quatro menos um quarto.** = It's 3:45.
> **A que horas?** = At what time?
> **Às oito.** = At eight.
> **meio-dia** = noon
> **meia-noite** = midnight

The most important distinction to get right is:

**Que horas são?** → asking **what time it is**
**A que horas?** → asking **at what time something happens**.

### ⭐ One important distinction

In English, **“town”** can mean a smaller urban place, but Portuguese doesn't use one single word in exactly the same way.

- **cidade** = city
- **vila** = town/small town
- **aldeia** = village
- **centro** = centre/downtown

So **“I'm in town”** often becomes **Estou na cidade** or, depending on context, **Estou no centro**.

## 🇵🇹 A1 Portuguese: Food & Drinks — Preferences

This topic teaches you how to say **what you like, dislike, prefer, want, and don't want** when talking about food and drinks.

---

# ❤️ 1. Gosto de — I like

The most important structure:

**Gosto de + food/drink**

| Portuguese | English |
|---|---|
| **Gosto de fruta.** | I like fruit. |
| **Gosto de arroz.** | I like rice. |
| **Gosto de frango.** | I like chicken. |
| **Gosto de peixe.** | I like fish. |
| **Gosto de café.** | I like coffee. |
| **Gosto de comida picante.** | I like spicy food. |

### With a specific item

**Gosto de maçãs.**
→ I like apples.

**Gosto de bananas.**
→ I like bananas.

**Gosto de bacalhau.**
→ I like cod.

---

# 👎 2. Não gosto de — I don't like

Simply put **não** before *gosto*:

**Não gosto de peixe.**
→ I don't like fish.

**Não gosto de cebola.**
→ I don't like onion.

**Não gosto de café.**
→ I don't like coffee.

**Não gosto de comida muito picante.**
→ I don't like very spicy food.

### Very useful distinction

**Não gosto de peixe.**
= I don't like fish.

**Não gosto muito de peixe.**
= I don't really like fish.

The second is softer.

---

# ⭐ 3. Gosto muito de — I really like

**Gosto muito de frango.**
→ I really like chicken.

**Gosto muito de fruta.**
→ I really like fruit.

**Gosto muito de comida portuguesa.**
→ I really like Portuguese food.

You can strengthen it:

**Adoro pizza.**
→ I love pizza.

**Adoro café.**
→ I love coffee.

---

# 😐 4. Não gosto nada de — I really don't like

**Não gosto nada de peixe.**
→ I really don't like fish.

**Não gosto nada de cebola.**
→ I really don't like onion.

This is stronger than **não gosto de**.

---

# 🥇 5. Preferências — Prefer

The basic verb is:

**preferir = to prefer**

**Prefiro café.**
→ I prefer coffee.

**Prefiro chá.**
→ I prefer tea.

**Prefiro frango.**
→ I prefer chicken.

### Comparing two things

**Prefiro café a chá.**
→ I prefer coffee to tea.

**Prefiro peixe a carne.**
→ I prefer fish to meat.

For A1, however, **Prefiro café** is enough initially.

---

# 🔄 6. Gosto mais de...

Another very useful way to express preference:

**Gosto mais de café.**
→ I like coffee more.

**Gosto mais de peixe.**
→ I like fish more.

**Gosto mais de fruta do que de legumes.**
→ I like fruit more than vegetables.

---

| **frio** | cold |
| **fresco** | fresh |
